# 拾词 Wordwise

![拾词图标](icons/icon128.png)

拾词是一款 Chrome 扩展，在阅读英文网页时为较难的词汇就地标注译文。你可以按自己的英语水平控制标注数量，不必为了查词频繁离开页面。

## 安装

目前请通过开发者模式安装：

1. 在[项目仓库](https://github.com/rossroma/word-wise)下载源码 ZIP 并解压，或运行 `git clone https://github.com/rossroma/word-wise.git`。
2. 打开 `chrome://extensions/`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目文件夹。
4. 在浏览器工具栏找到「拾词 - Wordwise」。如未显示，请在扩展菜单中将其固定。

> 更新本地安装的版本后，请在扩展程序页面点击「重新加载」，并刷新已经打开的网页。

## 开始阅读

1. 打开英文网页。如果未开启自动翻译，且当前网站不在白名单或黑名单中，页面右侧会显示一个「译」按钮；点击即可翻译本页。按钮可以沿屏幕右侧上下拖动，位置会被记住。
2. 较难词汇后会直接显示括号译文。与原词相同、仅大小写不同或只是简单单复数变化的译文不会显示。
3. 点击浏览器工具栏里的拾词图标，可以查看当前页面状态、译词数，并切换当前页面的翻译状态；点击「偏好设置」打开设置页。

插件只在检测到英文页面时自动开始工作。Chrome 内部页面等不支持内容脚本的页面不能使用翻译功能。

## 设置适合自己的翻译方式

在设置页修改选项后，点击「保存设置」。

- **自动翻译英文网页**：开启后，在检测到英文网页时自动翻译；关闭后可使用网页右侧按钮手动开始。网站规则优先于此开关。
- **英语水平**：在 A1、A2、B1、B2、C1、C2 间选择；档位越高，通常标注的词越少。默认 B2。实际标注数量会随文章内容变化。
- **译文语言**：可选简体中文、繁體中文、日本語和 한국어；不同引擎支持情况可能不同，LLM 引擎目前的提示词以中文译文为主。
- **翻译引擎**：默认按已配置的密钥选择 LLM、DeepL；没有云端密钥时使用 Chrome 内置翻译。请求失败不会自动切换到其他引擎。也可以指定单个引擎。

### 无需 API Key 使用

在「翻译引擎」中选择「Chrome 内置离线翻译」，或保持自动模式且不填写云端服务密钥。此模式无需付费密钥，翻译在浏览器本机进行。需要支持内置翻译的 Chrome 版本（设置页提示 Chrome 138+）；首次使用可能需要下载语言包。

### 使用 DeepL 或 LLM

- **DeepL**：在 [DeepL API](https://www.deepl.com/pro-api) 申请密钥，在设置页选择 DeepL 并填写「DeepL API Key」。
- **LLM（OpenAI 兼容）**：从 [OpenAI API Keys](https://platform.openai.com/api-keys) 或兼容服务取得密钥，选择 LLM 并填写 API Key；按需修改模型名称和 API 基地址。
- **自动选择**：展开「配置可选的翻译服务」后填写密钥，即可按优先级自动选用已配置的服务。

使用云端引擎可能产生服务商费用，相关请求会发送给所选服务。密钥保存在浏览器的同步存储中；如果启用了浏览器同步，密钥可能随浏览器账户同步。

设置页还提供网站规则、恢复默认、清除翻译缓存及调试日志开关。白名单网站即使关闭全局自动翻译也会自动开始；黑名单优先于白名单和全局开关，禁止自动翻译及手动启用。规则可写裸域名（包含其子域名）、`*.example.com`（仅子域名）、`example.*`，或 `https://example.com/docs/*`（精确协议与路径）；路径中的 `*` 可匹配任意字符。不能单独输入 `*` 来匹配所有网站；全局行为请使用自动翻译开关。规则只匹配 HTTP(S) 网站，保存后刷新网页可让自动翻译设置重新生效；已打开页面新加入黑名单时会立即停止翻译。白名单页手动关闭翻译后，刷新页面会按白名单再次自动开启。切换引擎后若想确认实际调用结果，可先清除缓存，再在英文网页上重试。

## 遇到问题？

- **按钮没有出现**：确认网页为英文内容、页面已刷新且不是 `chrome://` 等浏览器内部页面；如果开启了自动翻译，网页侧边按钮不会出现。
- **没有译文**：检查翻译引擎设置。使用 Chrome 内置翻译时确认浏览器版本和语言包可用；使用 DeepL/LLM 时检查密钥和额度。
- **切换引擎后结果未变**：在设置页清除翻译缓存，再刷新网页。
- **需要排查日志**：在设置页开启「调试日志」，刷新目标网页后查看网页控制台或扩展的 Service Worker 控制台。错误信息即使关闭调试日志也会保留。

仍无法解决？请在 [GitHub Issues](https://github.com/rossroma/word-wise/issues) 反馈，附上 Chrome 版本、扩展版本、复现网页及操作步骤；提交截图或日志前请先移除 API Key 等敏感信息。

## 本地开发

运行 `npm ci` 安装开发依赖，`npm run lint` 检查手写 JavaScript（包括扩展代码、`lib/`、`tools/` 和 `tests/`），`npm test` 运行测试。自动生成的 `lib/en-zipf.js` 不参与 lint；如需更新它，请修改生成脚本后重新生成。

### 本地语料基准

要对比不同阅读难度在多类样本中的匹配量，可运行 `npm run analyze:corpus`；完整候选词和未选中词可用 `npm run analyze:corpus -- --json` 查看。语料快照与来源见 `tests/corpus/long-fixtures.json` 和 `tests/corpus/sources.json`；运行 `python3 tools/fetch_corpus.py` 可刷新公版/政府语料。样本包括三种不同风格小说、一篇随笔、一篇 Python 软件工程文章、一篇医学报告，以及新闻与健康科普。版权受限的网页只保留来源 URL，不随项目分发正文。文学与软件样本为开头约 24,000 字符；新闻和科普较短，不能代表整个体裁。

**完整未收录词清单**：运行 `uv run --no-project --with wordfreq==3.1.1 python tools/classify_absent.py`（需安装 `uv`，仅分析工具依赖 wordfreq）。`tests/corpus/absent-words.csv` 逐文章列出每一个整词未收录项、原始写法、出现次数、上游 Zipf、筛选器 Zipf、分类和被哪些级别选中；`tests/corpus/absent-vocabulary.csv` 是跨文章去重的总清单，`tests/corpus/absent-summary.json` 是分类汇总。分类是启发式推断，不等于“应该翻译/过滤”的决策：`capitalized-surface-review` 只表示出现过首字母大写形式（包括句首、标题），**不能视为专名标签**。旧版 `tools/analyze_oov.py` 可选用于对照实际 OOV 的上游频率。“整词未收录”指本地裁剪词频表没有该词；“实际 OOV”指筛选器计算得到 Zipf=0，两者不等于完整 wordfreq 不收录。已选中、未选中及整词未收录占比以该样本去重词数为分母，出现次数占比以总词语出现次数为分母；每档 OOV% 以该档已选中的去重词数为分母。所有数字是翻译前候选数，不代表实际显示的译文。
