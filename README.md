# 拾词 Wordwise

![拾词图标](icons/icon128.png)

拾词是一款 Chrome 扩展，在阅读英文网页时为较难的词汇就地标注译文。你可以按自己的英语水平控制标注数量，不必为了查词频繁离开页面。

## 安装

目前请通过开发者模式安装：

1. 在[项目仓库](https://github.com/rossroma/word-wise)下载源码 ZIP 并解压，或运行 `git clone https://github.com/rossroma/word-wise.git`。
2. 打开 `chrome://extensions/`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目文件夹。
4. 在浏览器工具栏找到「拾词 - Wordwise」。如未显示，请在扩展菜单中将其固定。

> 更新本地安装的版本后，请在扩展程序页面点击「重新加载」，并刷新已经打开的网页。

## 开始阅读

1. 打开英文网页。如果未开启自动翻译，页面右侧会显示一个「译」按钮；点击即可翻译本页。按钮可以沿屏幕右侧上下拖动，位置会被记住。
2. 较难词汇后会直接显示括号译文。与原词相同、仅大小写不同或只是简单单复数变化的译文不会显示。
3. 点击浏览器工具栏里的拾词图标，可以查看当前页面状态、译词数，并切换当前页面的翻译状态；点击「偏好设置」打开设置页。

插件只在检测到英文页面时自动开始工作。Chrome 内部页面等不支持内容脚本的页面不能使用翻译功能。

## 设置适合自己的翻译方式

在设置页修改选项后，点击「保存设置」。

- **自动翻译英文网页**：开启后，在检测到英文网页时自动翻译；关闭后可使用网页右侧按钮手动开始。
- **英语水平**：在 A2、B1、B2、C1、C2 间选择；档位越高，通常标注的词越少。默认 B2。
- **译文语言**：可选简体中文、繁體中文、日本語和 한국어；不同引擎支持情况可能不同，LLM 引擎目前的提示词以中文译文为主。
- **翻译引擎**：默认自动选择，优先使用已配置的 LLM，其次 DeepL，最后回退到 Chrome 内置翻译。也可以指定单个引擎。

### 无需 API Key 使用

在「翻译引擎」中选择「Chrome 内置离线翻译」，或保持自动模式且不填写云端服务密钥。此模式无需付费密钥，翻译在浏览器本机进行。需要支持内置翻译的 Chrome 版本（设置页提示 Chrome 138+）；首次使用可能需要下载语言包。

### 使用 DeepL 或 LLM

- **DeepL**：在 [DeepL API](https://www.deepl.com/pro-api) 申请密钥，在设置页选择 DeepL 并填写「DeepL API Key」。
- **LLM（OpenAI 兼容）**：从 [OpenAI API Keys](https://platform.openai.com/api-keys) 或兼容服务取得密钥，选择 LLM 并填写 API Key；按需修改模型名称和 API 基地址。
- **自动选择**：展开「配置可选的翻译服务」后填写密钥，即可按优先级自动选用已配置的服务。

使用云端引擎可能产生服务商费用，相关请求会发送给所选服务。密钥保存在浏览器的同步存储中；如果启用了浏览器同步，密钥可能随浏览器账户同步。

设置页还提供网站白名单与黑名单、恢复默认、清除翻译缓存及调试日志开关。切换引擎后若想确认实际调用结果，可先清除缓存，再在英文网页上重试。

## 遇到问题？

- **按钮没有出现**：确认网页为英文内容、页面已刷新且不是 `chrome://` 等浏览器内部页面；如果开启了自动翻译，网页侧边按钮不会出现。
- **没有译文**：检查翻译引擎设置。使用 Chrome 内置翻译时确认浏览器版本和语言包可用；使用 DeepL/LLM 时检查密钥和额度。
- **切换引擎后结果未变**：在设置页清除翻译缓存，再刷新网页。
- **需要排查日志**：在设置页开启「调试日志」，刷新目标网页后查看网页控制台或扩展的 Service Worker 控制台。错误信息即使关闭调试日志也会保留。

仍无法解决？请在 [GitHub Issues](https://github.com/rossroma/word-wise/issues) 反馈，附上 Chrome 版本、扩展版本、复现网页及操作步骤；提交截图或日志前请先移除 API Key 等敏感信息。
